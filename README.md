# Generator quizów AI

Projekt w Nuxt 4: podajesz temat, a model układa quiz. Potrzebujesz Node.js 22 LTS lub nowszego (co najmniej 22.12).

```
npm i
npm run dev
```

Otwórz http://localhost:3000. Klucz do modelu wpisz w pliku `.env` (wzór w `.env.example`).

## Windows

- Komendy wpisuj w `cmd`, nie w PowerShellu, bo PowerShell domyślnie blokuje skrypty npm.
- Plik `.env` utwórz komendą `copy .env.example .env` albo w VS Code. Notatnik zapisze go jako `.env.txt`.
- Nie trzymaj projektu na Pulpicie ani w Dokumentach, jeśli synchronizuje je OneDrive. Przenieś go np. do `C:\dev`.
